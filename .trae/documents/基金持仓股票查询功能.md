# 基金持仓股票信息查询功能

## Context

**为什么做**：用户希望在 ETF 基金详情页直接看到「这只基金买了哪些股票」的全貌，并能在站内闭环查询这些股票的公司概况、实时行情、K线、分时、财务指标和新闻，避免用户从基金页跳到第三方平台查。

**现状**：

- 基金详情页（`app/routes/fund.$code.tsx`）已经渲染 `heavy.topHoldings`，但**只取前 10 大重仓**（`market-data.ts:974` 的 `.slice(0, 10)`）
- 持仓股票只有代码/名称/价格/涨跌/占比 5 个字段，**没有跳转到股票详情的能力**（表格行不可点）
- 没有任何股票详情页、K线、分时、财务、新闻模块
- 基金持有的有美股（已有 sinajs.cn `gb_xxx` 路径）也有 A 股/港股（pingzhongdata `stockCodes` 里 6 位数字代码就是 A 股）

**用户已确认**（4 个关键决策）：

1. 范围 = 完整版（持仓列表 + 股票详情全功能）
2. 数据源 = 东方财富 datacenter + 腾讯行情
3. 持仓粒度 = top 10 默认展示 + 「查看全部持仓」展开
4. 实时更新 = 轮询（10-30s 间隔）

**预期结果**：

- 基金详情页「重仓股行情」区块升级为完整列表（top 10 卡片视图 + 全部持仓表格视图 + 搜索 + 排序 + 跳转）
- 新增 `/stock/:code` 路由展示单只股票：实时价 + 涨跌幅 + 成交量 + 日/周/月 K线 + 分时 + 公司概况 + 财务指标 + 近期新闻
- 数据全部走 `cachedFetch` + 东方财富 `push2/push2his/emweb` + 腾讯 `qt.gtimg.cn`，与现有 `market-data.ts` 风格一致

| 财务指标   | 东方财富 | `https://emweb.eastmoney.com/PC_HSF10/NewFinanceAnalysis/MainTargetAjax?code={prefix}{code}&type=0`                                                                                                                                              | 1d    | 季度披露           |

**市场前缀映射（secid 的 mkt）**：

- 6xxxxx → `1`（沪 A）
- 0xxxxx, 3xxxxx → `0`（深 A / 创业）
- 8xxxxx, 4xxxxx → `0`（京 A / 北交所）
- 5xxxxx → `1`（沪 ETF，本期不重点支持，但接口天然兼容）
- 港股 5 位数字 → `116`（港股先用占位 "港股板块暂未启用"，避免实时价接口跨市场误用）
- 美股字母 → `105`（gb_xxx 已经能拿到；本方案不复用 sinajs，统一走东方财富 push2）

> **简化决策**：本期只支持 **A 股**（沪/深/京）的股票详情，**美股**走 `getSinaUSStock` 已有路径，**港股**显式提示「港股详情建设中」。A 股 secid 通过代码首字符判断。

## 核心实现要点

### 1. `app/lib/stock-data.ts`（新文件，~300 行）

仿照 `market-data.ts` 风格，提供：

```ts
// 实时价（轮询，30s TTL）
export async function getStockQuote(
  code: string,
  opts?: { bypassCache?: boolean },
): Promise<{
  code;
  name;
  price;
  change;
  changePercent;
  open;
  high;
  low;
  prevClose;
  volume;
  turnover;
  timestamp;
  mkt: "sh" | "sz" | "bj";
  marketLabel: string;
}>;

// K线（1h TTL）
export async function getStockKLine(
  code: string,
  period: "1d" | "1w" | "1m",
  opts?: { bypassCache?: boolean },
): Promise<
  Array<{ date; open; close; high; low; volume; turnover; amplitude; changePercent; changeAmount }>
>;

// 分时（1min TTL）
export async function getStockMinuteTrend(
  code: string,
  opts?: { bypassCache?: boolean },
): Promise<Array<{ time; price; avgPrice; volume; turnover }>>;

// 公司概况（1d TTL）
export async function getStockCompanyInfo(code: string): Promise<{
  name;
  industry;
  listingDate;
  totalShares;
  circulatingShares;
  mainBusiness;
  profile;
} | null>;

// 财务指标（1d TTL）
export async function getStockFinancials(code: string): Promise<{
  eps;
  roe;
  grossMargin;
  debtRatio;
  pe;
  pb;
  ps;
  totalMarketCap;
  circulatingMarketCap;
  reportDate;
} | null>;

// 近期新闻（10min TTL）
export async function getStockNews(
  code: string,
): Promise<Array<{ title; summary; source; publishTime; url }>>;

// 内部工具
function detectMarket(code: string): { secid: number; prefix: "SH" | "SZ" | "BJ" };
// 6xxxxx → { secid: 1, prefix: "SH" }
// 0xxxxx/3xxxxx → { secid: 0, prefix: "SZ" }
// 8xxxxx/4xxxxx/9xxxxx → { secid: 0, prefix: "BJ" }
// 其它 → throw (港股/美股本期返回 null)
```

**所有函数共用 `cachedFetch` 和 `fetchJson`**，从 `~/lib/market-data` 导入复用（不重新实现）。

**降级约定**：所有函数返回 `null` 而不是抛错；`getStockQuote` 即使失败也返回带 `price=0, changePercent=0` 的占位，UI 显示 `—` 和"数据获取失败"提示（参考 `getFundHeavyData` 的兜底风格）。

### 2. `app/components/stock/kline-chart.tsx`（K线核心，~150 行）

- 复用 `use-echarts` + `ChartShell`
- series: `candlestick`（OHLC 4 个维度）+ `line`（MA5/MA10/MA20 均线）
- 周期切换按钮组（近 1 月 / 3 月 / 6 月 / 1 年 / 全部），仿 `fund-nav-trend-chart.tsx` 的 `RANGES` 模式
- 用 ECharts 内置的 `dataZoom` 缩放（已封装在 `getDataZoom`）
- 涨跌色：复用 `chart-utils.ts` 的 `upColor`/`downColor`（已是中国市场习惯的红涨绿跌）

### 3. `app/components/stock/minute-chart.tsx`（分时，~80 行）

- ECharts `line` 两条线：实时价（实线）+ 当日均价（虚线）
- 加一条昨收价水平参考线（`markLine`）
- 240 个数据点（4 小时交易时间 × 60 分钟）
- 休市时（24h 外）显示「当前为非交易时段，分时图展示最近一个交易日」+ 仍渲染图表

### 4. `app/components/stock/holdings-table.tsx`（完整持仓表格，~200 行）

功能：

- **搜索框**：按代码 / 名称模糊匹配（防抖 200ms，参考 `app/hooks/use-navigation-debounce.ts` 模式）
- **排序**：列点击切换 asc/desc/默认；支持列：代码、名称、持仓占比、持股数量、最新价、当日涨跌幅
- **视图切换**：默认展示前 10（卡片式，参考现有 `holdings-pie-chart` 旁边的 table）；底部「展开全部持仓」按钮切到完整表格（虚拟滚动，避免 300 行卡顿——用 `react-window`? **不引入新依赖**，用 CSS `content-visibility: auto` + 简单分页 50/页）
- **行点击**：跳转 `/stock/{code}`（A 股）或 `/stock/us/{code}`（美股走 `/fund/...` 已有的 `getSinaUSStock` 占位）
- **降级**：持仓数据为空时显示「暂无持仓数据」

### 5. `app/routes/stock.$code.tsx`（新路由，~350 行）

- 复用 `fund.$code.tsx` 的 `AsyncSection` + Skeleton + `FundDetailWithRetry` 状态机
- `meta()`：动态 title「贵州茅台（600519）股票详情 - 实时行情/K线/分时」+ description
- loader 走全 defer（quote / kline / minute / info / financials / news 都不 await）
- 404：URL 首位非数字（不是 6/0/3/8/4 开头）→ `meta()` 加 noindex + 显示「股票代码不存在或暂不支持」
- 港股：直接显示「港股板块建设中，敬请期待」，不调接口
- 轮询：客户端 `useStockPoll(code, 15_000)` 调 `getStockQuote(code, { bypassCache: true })`；**带可见性暂停**（`document.visibilityState !== "visible"` 时停掉）

### 6. `app/routes/fund.$code.tsx` 修改

把 `FundHeavyContent` 里的「重仓股行情」区块（约 line 444-499）替换为 `<HoldingsTable holdings={heavy.topHoldings} fullCount={...} />`。**heavy.topHoldings 字段保持兼容**（symbol/name/price/changePercent/holdingRatio），但 getFundHeavyData 内部要返回**完整列表**（去掉 `.slice(0, 10)`），新增 `topCount` 字段（真实取了多少条）。

### 7. SEO 与菜单

- `app/lib/seo.ts` 新增 `buildStockJsonLd({ code, name, price, changePercent, marketLabel, path })`，输出 `Quotation` schema（schema.org 的金融报价类型）
- `app/components/app-header/menu-config.ts` **不加新菜单**——股票是基金页的二级页，从持仓表行点击进入即可
- `app/routes.ts` 加：`route("stock/:code", "routes/stock.$code.tsx")`
- `app/routes/sitemap[.]xml.ts` 加：sitemap 中暂不收录 `/stock/:code`（代码空间太大，避免爬虫抓海量垃圾 URL）

## 风险与边界

- **东方财富 push2 接口**有频率限制（实测 ~20 QPS 安全），轮询 15s × 单用户 = 0.067 QPS，可接受；但需要保证 `bypassCache` 路径不会高频打源站（客户端单页 1 个轮询 + 首次进页拉一次）
- **新闻接口** `search-api-web.eastmoney.com` 偶发 403，需 fallback 到 `his-search`（暂不实现，先 try/catch 静默）
- **分时图**非交易时段永远显示最近一个交易日，需要 UI 上加灰色提示带
- **港股/美股**本期不实现详情页，但持仓表里要能显示这两类股票的基础信息（复用现有 pingzhongdata 解析逻辑）
- **完整持仓列表**字段会比 topHoldings 少（季报披露的股票只有代码+名称+占比+持股数，没有实时价）；需要单独走一次 `getStockQuote` 给每只持仓拉价（5min 缓存 + 批量接口 `push2.eastmoney.com/api/qt/stock/get` 支持多 secid）
- **batch 实时价**：`https://push2.eastmoney.com/api/qt/stock/get?secid=1.600519,0.000001&fields=...` 支持一次拉多只；用这个替代逐只 `getStockQuote` 拉完整持仓列表
